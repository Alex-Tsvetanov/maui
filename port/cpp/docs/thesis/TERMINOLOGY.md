# Терминологични решения (български)

Работен речник за дипломната работа. Целта му е една: **един термин — една дума**, за да
не се появят три превода на едно понятие в три раздела. Записан е и защото част от
първоначалните избори бяха буквални преводи от английски, които на български значат друго.

## Поправени лъжливи приятели

| Беше | Стана | Защо |
| --- | --- | --- |
| присъда | **оценка** | „присъда“ е съдебен акт; резултат от измерване е оценка |
| отсъждане | **оценяване** | от същото съдебно семейство |
| приемник (за layout container) | **контейнер** | „приемник“ значи наследник/получател |
| обслужващ обект (handler) | **обработчик** | „обслужващ обект“ е измислена дума; „обработчик“ съществува |
| приведение (coercion) | **привеждане** | русизъм |
| лента (в смисъл „platform lane“) | **платформа** | „лента“ е ивица; запазено САМО за „системна лента“ |
| шев (seam) | **граница** | буквален превод на *seam*; на български не значи това |
| по построение (by construction) | **по замисъл** | математически оборот, звучи преведено в инженерен текст |

## Приети термини

| Английски | Български | Бележка |
| --- | --- | --- |
| handler | обработчик | таблично управляван, не обработчик на събитие — дефиниран в §1.3.1 |
| virtual view | виртуален изглед | термин на еталонната архитектура; въведен с определение |
| contract / interface | договор | по аналогия с „проектиране по договор“ |
| layout | разположение | „оформление“ се избягва — заето за типография |
| measure / arrange | измерване / подреждане | двете фази |
| margin / padding | външен / вътрешен отстъп | НИКОГА само „отстъп“ |
| property | свойство | |

| value precedence | предимство на стойностите | |
| toolkit | инструментариум | „native инструментариум“ за платформения |
| runtime | среда за изпълнение | |

## Какво остава

Тази редакция поправя **терминологията и буквалните изрази**, не ритъма на изречението.
Български научен текст, писан с английски синтактичен модел, остава разпознаваем по
дължината на изреченията и по реда на подчинените изречения дори когато всяка дума е
вярна. Преди предаване текстът се нуждае от прочит от носител на езика точно за това.
