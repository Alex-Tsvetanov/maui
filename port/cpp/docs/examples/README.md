# MAUI C++ examples — previews

Per-platform **C++** and **C++&amp;XAML** previews of the standalone example apps in `port/cpp/examples/` (the non-gallery ones). Each example shows an **iOS + Android** table and a **macOS** table (macOS adds the AppKit backend columns); every row stacks the Light render over the Dark one. Screenshots live under `docs/examples/<name>/{maui,cpp,xaml}/`; cells with no capture yet show a placeholder. Generated from the example folders by `../comparison/tools/gen_examples_readme.py`.
