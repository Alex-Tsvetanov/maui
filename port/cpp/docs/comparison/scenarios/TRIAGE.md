# Interaction triage — 2026-08-06

Which board pages can be driven TODAY without a library change.

A scenario is board-safe when the visible change is CONTROL-INTRINSIC: the native control repaints
itself with no app handler. All three columns then react identically. It is NOT safe when the change
is HANDLER-DRIVEN, because the shared XAML twins omit handlers while the code-first cpp column has
them (113 of 179 builder pages call .connect()) — driving those manufactures a red that says nothing
about rendering.

Triaged 101 pages. Evidence cites BOTH columns per page.
