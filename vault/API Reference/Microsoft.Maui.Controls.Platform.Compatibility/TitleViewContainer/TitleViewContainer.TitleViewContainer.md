# TitleViewContainer.TitleViewContainer

> [!abstract] Constructor of [[TitleViewContainer|TitleViewContainer]]
> Namespace: `Microsoft.Maui.Controls.Platform.Compatibility`

Creates a TitleViewContainer with an explicitly set frame from the navigation bar. Used on iOS 26+ to ensure proper sizing when using autoresizing masks.

## Signature

```csharp
void TitleViewContainer(Microsoft.Maui.Controls.View view)
```

## Parameters

| Parameter | Description |
|---|---|
| `view` | The MAUI view to display in the title |
| `navigationBarFrame` | The navigation bar frame to use for sizing |
