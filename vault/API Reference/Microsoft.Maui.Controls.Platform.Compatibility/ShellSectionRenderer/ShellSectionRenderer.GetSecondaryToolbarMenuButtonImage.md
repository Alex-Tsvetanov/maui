# ShellSectionRenderer.GetSecondaryToolbarMenuButtonImage

> [!abstract] Method of [[ShellSectionRenderer|ShellSectionRenderer]]
> Namespace: `Microsoft.Maui.Controls.Platform.Compatibility`

Override this method to provide a custom image for the secondary toolbar menu button. The default implementation uses the "ellipsis.circle" system image. This image is used for the menu button that appears when there are secondary toolbar items

## Signature

```csharp
UIKit.UIImage virtual GetSecondaryToolbarMenuButtonImage()
```

## Returns

The image to use for the secondary toolbar menu button.
