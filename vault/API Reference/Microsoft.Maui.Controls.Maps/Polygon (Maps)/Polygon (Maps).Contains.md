# Polygon (Maps).Contains

> [!abstract] Method of [[Polygon (Maps)|Polygon (Maps)]]
> Namespace: `Microsoft.Maui.Controls.Maps`

Returns whether the specified location is contained in this polygon.

## Signature

```csharp
bool Contains(Microsoft.Maui.Devices.Sensors.Location! item)
```

## Parameters

| Parameter | Description |
|---|---|
| `item` | The location object of which to determine if it is contained in the location collection of this polygon. |

## Returns

`true` if `item` is contained in the location collection of this polygon, otherwise `false`.
