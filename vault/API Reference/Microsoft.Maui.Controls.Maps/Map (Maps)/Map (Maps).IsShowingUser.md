# Map (Maps).IsShowingUser

> [!abstract] Property of [[Map (Maps)|Map (Maps)]]
> Namespace: `Microsoft.Maui.Controls.Maps`

Gets or sets a value that indicates if the map shows an indicator of the current position of this device. Default value is `false` This is a bindable property.

## Signature

```csharp
bool IsShowingUser { get; set; }
```

## Remarks

Depending on the platform it is likely that runtime permission(s) need to be requested to determine the current location of the device.
