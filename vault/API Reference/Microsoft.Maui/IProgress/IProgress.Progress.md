# IProgress.Progress

> [!abstract] Property of [[IProgress|IProgress]]
> Namespace: `Microsoft.Maui`

Is a value that represents the current progress as a value from 0 to 1. Progress values less than 0 will be clamped to 0, values greater than 1 will be clamped to 1.
