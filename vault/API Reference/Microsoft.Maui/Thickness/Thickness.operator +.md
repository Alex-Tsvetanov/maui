# Thickness.operator +

> [!abstract] Operator of [[Thickness|Thickness]]
> Namespace: `Microsoft.Maui`

Adds a uniform value to all edges of the thickness.

## Signatures

```csharp
Microsoft.Maui.Thickness static operator +(Microsoft.Maui.Thickness left, double addend)
Microsoft.Maui.Thickness static operator +(Microsoft.Maui.Thickness left, Microsoft.Maui.Thickness right)
```

## Returns

A new thickness with adjusted edges.

## Parameters

| Parameter | Description |
|---|---|
| `left` | The original thickness. |
| `addend` | The value to add to each edge. |
