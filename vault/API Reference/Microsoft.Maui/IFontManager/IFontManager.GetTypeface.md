# IFontManager.GetTypeface

> [!abstract] Method of [[IFontManager|IFontManager]]
> Namespace: `Microsoft.Maui`

Retrieves the platform equivalent `Typeface` for an abstract `Font` object.

## Signature

```csharp
Android.Graphics.Typeface? GetTypeface(Microsoft.Maui.Font font)
```

## Returns

The `Typeface` object representing the font as provided in `font`.

## Parameters

| Parameter | Description |
|---|---|
| `font` | The abstract font representation to get the platform equivalent for. |
