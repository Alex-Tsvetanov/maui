# WebViewInitializationStartedEventArgs.BrowserExecutableFolder

> [!abstract] Property of [[WebViewInitializationStartedEventArgs|WebViewInitializationStartedEventArgs]]
> Namespace: `Microsoft.Maui`

## Signature

```csharp
string? BrowserExecutableFolder { get; set; }
```

## Remarks

To use a fixed version of the WebView2 Runtime, set this property to the folder path that contains the fixed version of the WebView2 Runtime.
