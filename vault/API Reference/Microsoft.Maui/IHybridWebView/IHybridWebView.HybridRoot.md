# IHybridWebView.HybridRoot

> [!abstract] Property of [[IHybridWebView|IHybridWebView]]
> Namespace: `Microsoft.Maui`

The path within the app's "Raw" asset resources that contain the web app's contents. For example, if the files are located in [ProjectFolder]/Resources/Raw/hybrid_root , then set this property to "hybrid_root". The default value is wwwroot , which maps to [ProjectFolder]/Resources/Raw/wwwroot .
