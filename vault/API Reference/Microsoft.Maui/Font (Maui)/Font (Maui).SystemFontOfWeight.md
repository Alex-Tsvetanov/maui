# Font (Maui).SystemFontOfWeight

> [!abstract] Method of [[Font (Maui)|Font (Maui)]]

```csharp
Microsoft.Maui.Font static SystemFontOfWeight(Microsoft.Maui.FontWeight weight, Microsoft.Maui.FontSlant fontSlant = Microsoft.Maui.FontSlant.Default, bool enableScaling = true)
```

| Parameter | Description |
|---|---|
