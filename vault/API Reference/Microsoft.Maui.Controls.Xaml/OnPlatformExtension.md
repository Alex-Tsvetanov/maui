# OnPlatformExtension

> [!abstract] Class in `Microsoft.Maui.Controls.Xaml`
> Full name: `Microsoft.Maui.Controls.Xaml.OnPlatformExtension`

Provides a XAML markup extension that returns different values depending on the platform the app is running on.
