# Animation (Animations).CreateAutoReversing

> [!abstract] Method of [[Animation (Animations)|Animation (Animations)]]
> Namespace: `Microsoft.Maui.Animations`

Creates an animation that includes both the original animation and a reversed version of the same animation.

## Signature

```csharp
Microsoft.Maui.Animations.Animation! CreateAutoReversing()
```

## Returns

An `Animation` object with the original animation and the reversed animation.

## Remarks

You can get just the reversed animation by using `CreateReverse`.
