# WDSkiaDirectRenderer.SizeChanged

> [!abstract] Method of [[WDSkiaDirectRenderer|WDSkiaDirectRenderer]]
> Namespace: `Microsoft.Maui.Graphics.Skia`

Notifies the renderer that the size of the drawing surface has changed.

## Signature

```csharp
void SizeChanged(int width, int height)
```

## Parameters

| Parameter | Description |
|---|---|
| `width` | The new width of the drawing surface. |
| `height` | The new height of the drawing surface. |

## Remarks

This implementation does not perform any actions when the size changes.
