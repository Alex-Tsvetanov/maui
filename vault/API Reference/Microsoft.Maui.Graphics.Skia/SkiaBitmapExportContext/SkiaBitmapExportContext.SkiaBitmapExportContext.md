
## Parameters

| Parameter | Description |
|---|---|
| `width` | The width of the bitmap in pixels. |
| `height` | The height of the bitmap in pixels. |
| `displayScale` | The display scale factor to use. |
| `dpi` | The dots per inch (DPI) of the bitmap. Default is 72. |
| `disposeBitmap` | Whether to dispose the bitmap when this context is disposed. |
| `transparent` | Whether the bitmap should have an alpha channel (transparency). |
