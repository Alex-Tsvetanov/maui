# SkiaCanvas.FillArc

> [!abstract] Method of [[SkiaCanvas|SkiaCanvas]]
> Namespace: `Microsoft.Maui.Graphics.Skia`

Fills an arc within the specified rectangle from the start angle to the end angle.

## Signature

```csharp
void override FillArc(float x, float y, float width, float height, float startAngle, float endAngle, bool clockwise)
```

## Parameters

| Parameter | Description |
|---|---|
| `x` | The x-coordinate of the upper-left corner of the rectangle that contains the arc. |
| `y` | The y-coordinate of the upper-left corner of the rectangle that contains the arc. |
| `width` | The width of the rectangle that contains the arc. |
| `height` | The height of the rectangle that contains the arc. |
| `startAngle` | The starting angle in degrees. |
| `endAngle` | The ending angle in degrees. |
| `clockwise` | A value indicating whether the arc is drawn clockwise or counterclockwise. |
