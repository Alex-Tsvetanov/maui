# VisualElement (TizenSpecific)

> [!abstract] Class in `Microsoft.Maui.Controls.PlatformConfiguration.TizenSpecific`
> Full name: `Microsoft.Maui.Controls.PlatformConfiguration.TizenSpecific.VisualElement`
