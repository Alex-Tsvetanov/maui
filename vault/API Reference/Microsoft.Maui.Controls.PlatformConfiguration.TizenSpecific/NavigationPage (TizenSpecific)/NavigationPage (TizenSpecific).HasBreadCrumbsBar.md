# NavigationPage (TizenSpecific).HasBreadCrumbsBar

> [!abstract] Method of [[NavigationPage (TizenSpecific)|NavigationPage (TizenSpecific)]]
> Namespace: `Microsoft.Maui.Controls.PlatformConfiguration.TizenSpecific`

Returns a Boolean value that tells whether the navigation page has a bread crumb bar.

## Signature

```csharp
bool static HasBreadCrumbsBar(this Microsoft.Maui.Controls.IPlatformElementConfiguration<Microsoft.Maui.Controls.PlatformConfiguration.Tizen, Microsoft.Maui.Controls.NavigationPage> config)
```

## Parameters

| Parameter | Description |
|---|---|
| `config` | The platform configuration for the navigation page on the Tizen platform whose font weight icon to get. |

## Returns

`true` if the navigation page has a bread crumb bar. Otherwise, `false`.
