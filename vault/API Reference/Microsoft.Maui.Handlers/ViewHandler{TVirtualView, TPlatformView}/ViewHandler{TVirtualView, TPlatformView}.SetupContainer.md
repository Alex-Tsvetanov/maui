# ViewHandler<TVirtualView, TPlatformView>.SetupContainer

> [!abstract] Method of [[ViewHandler{TVirtualView, TPlatformView}|ViewHandler<TVirtualView, TPlatformView>]]
> Namespace: `Microsoft.Maui.Handlers`

Gets or sets a value that indicates whether the `PlatformView` is contained within a view.

## Signature

```csharp
void override Microsoft.Maui.Handlers.ViewHandler<TVirtualView, TPlatformView>.SetupContainer()
```

## Remarks

When set to `true`, `SetupContainer` is called to setup the container view. When set to `false`, `RemoveContainer` is called to remove the current container view.
