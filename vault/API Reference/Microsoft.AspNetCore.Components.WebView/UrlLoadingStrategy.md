# UrlLoadingStrategy

> [!abstract] Enum in `Microsoft.AspNetCore.Components.WebView`
> Full name: `Microsoft.AspNetCore.Components.WebView.UrlLoadingStrategy`

URL loading strategy for anchor tags ]]> within a Blazor WebView. Anchor tags with target="_blank" will always open in the default browser and the UrlLoading event won't be called.
