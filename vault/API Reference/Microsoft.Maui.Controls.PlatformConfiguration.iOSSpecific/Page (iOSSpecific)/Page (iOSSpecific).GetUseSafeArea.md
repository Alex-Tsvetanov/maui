# Page (iOSSpecific).GetUseSafeArea

> [!abstract] Method of [[Page (iOSSpecific)|Page (iOSSpecific)]]
> Namespace: `Microsoft.Maui.Controls.PlatformConfiguration.iOSSpecific`

Gets a value that indicates whether padding values are overridden with values that conform to the safe area on the device.

## Signature

```csharp
bool static GetUseSafeArea(Microsoft.Maui.Controls.BindableObject element)
```

## Parameters

| Parameter | Description |
|---|---|
| `element` | The element to get the safe area behavior from. |

## Returns

`true` if the padding values are overridden; otherwise, `false`.

## Remarks

This API is deprecated. Use SafeAreaEdges attached property instead for per-edge safe area control.
