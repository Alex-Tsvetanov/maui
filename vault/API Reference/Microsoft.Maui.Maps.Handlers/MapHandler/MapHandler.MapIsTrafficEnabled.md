# MapHandler.MapIsTrafficEnabled

> [!abstract] Method of [[MapHandler|MapHandler]]
> Namespace: `Microsoft.Maui.Maps.Handlers`

Maps `IsTrafficEnabled` via the Azure Maps JS map.setTraffic() API.

## Signature

```csharp
void static MapIsTrafficEnabled(Microsoft.Maui.Maps.Handlers.IMapHandler! handler, Microsoft.Maui.Maps.IMap! map)
```

## Remarks

When enabled, shows traffic flow (color-coded roads) and incident icons. When disabled, removes both traffic flow and incident overlays.
