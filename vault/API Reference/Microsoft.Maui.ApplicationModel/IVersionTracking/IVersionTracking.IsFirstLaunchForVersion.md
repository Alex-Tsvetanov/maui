# IVersionTracking.IsFirstLaunchForVersion

> [!abstract] Method of [[IVersionTracking|IVersionTracking]]
> Namespace: `Microsoft.Maui.ApplicationModel`

Determines if this is the first launch of the app for a specified version number.

## Signature

```csharp
bool IsFirstLaunchForVersion(string! version)
```

## Returns

`true` if this is the first launch of the app for the specified version number; otherwise `false`.

## Parameters

| Parameter | Description |
|---|---|
| `version` | The version number. |
