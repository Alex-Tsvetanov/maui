# RoundRectangle.CornerRadius

> [!abstract] Property of [[RoundRectangle|RoundRectangle]]
> Namespace: `Microsoft.Maui.Controls.Shapes`

Gets or sets the corner radius for the round rectangle.

## Signature

```csharp
Microsoft.Maui.CornerRadius CornerRadius { get; set; }
```

## Remarks

When specifying corner radii, the order of values is top left, top right, bottom left, and bottom right.
