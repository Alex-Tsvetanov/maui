# GeometryHelper

> [!abstract] Class in `Microsoft.Maui.Controls.Shapes`
> Full name: `Microsoft.Maui.Controls.Shapes.GeometryHelper`

Provides helper methods for geometry operations such as flattening curves into polylines.

## Methods

| Name | Summary |
|---|---|
| [[GeometryHelper.FlattenArc\|FlattenArc]] | Flattens an elliptical arc into a series of line segments. |
| [[GeometryHelper.FlattenCubicBezier\|FlattenCubicBezier]] | Flattens a cubic Bezier curve into a series of line segments. |
| [[GeometryHelper.FlattenGeometry\|FlattenGeometry]] | Flattens a `Geometry` into a `PathGeometry` containing only polyline segments. |
| [[GeometryHelper.FlattenQuadraticBezier\|FlattenQuadraticBezier]] | Flattens a quadratic Bezier curve into a series of line segments. |
