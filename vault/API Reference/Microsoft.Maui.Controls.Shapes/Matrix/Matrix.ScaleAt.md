# Matrix.ScaleAt

> [!abstract] Method of [[Matrix|Matrix]]
> Namespace: `Microsoft.Maui.Controls.Shapes`

Appends a scale transformation around the specified point to this matrix.

## Signature

```csharp
void ScaleAt(double scaleX, double scaleY, double centerX, double centerY)
```

## Parameters

| Parameter | Description |
|---|---|
| `scaleX` | The scale factor along the X axis. |
| `scaleY` | The scale factor along the Y axis. |
| `centerX` | The X coordinate of the scale center. |
| `centerY` | The Y coordinate of the scale center. |
