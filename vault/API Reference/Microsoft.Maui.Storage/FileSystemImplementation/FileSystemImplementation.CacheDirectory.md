# FileSystemImplementation.CacheDirectory

> [!abstract] Property of [[FileSystemImplementation|FileSystemImplementation]]
> Namespace: `Microsoft.Maui.Storage`

Gets the location where temporary data can be stored.

## Signature

```csharp
string! CacheDirectory { get; }
```

## Remarks

This location usually is not visible to the user, is not backed up, and may be cleared by the operating system at any time.
