# IPreferences.ContainsKey

> [!abstract] Method of [[IPreferences|IPreferences]]
> Namespace: `Microsoft.Maui.Storage`

Checks for the existence of a given key.

## Signature

```csharp
bool ContainsKey(string! key, string? sharedName = null)
```

## Returns

`true` if the key exists in the preferences, otherwise `false`.

## Parameters

| Parameter | Description |
|---|---|
| `key` | The key to check. |
| `sharedName` | Shared container name. |
