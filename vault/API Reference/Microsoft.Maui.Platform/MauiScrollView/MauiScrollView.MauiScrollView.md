# MauiScrollView.MauiScrollView

> [!abstract] Constructor of [[MauiScrollView|MauiScrollView]]
> Namespace: `Microsoft.Maui.Platform`

Flag indicating whether this scroll view should apply safe area adjustments to its content. Only true when not nested in another scroll view, no parent MauiView handles it, and safe area is not empty.
