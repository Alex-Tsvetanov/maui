# IPlatformMeasureInvalidationController.InvalidateAncestorsMeasuresWhenMovedToWindow

> [!abstract] Method of [[IPlatformMeasureInvalidationController|IPlatformMeasureInvalidationController]]
> Namespace: `Microsoft.Maui.Platform`

Schedules measure invalidation to occur when the view is moved to a window. This is used to handle scenarios where invalidation is attempted before the view is attached to a window.
