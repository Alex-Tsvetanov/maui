# MapSpan.WithZoom

> [!abstract] Method of [[MapSpan|MapSpan]]
> Namespace: `Microsoft.Maui.Maps`

Determines whether two `MapSpan` instances are not equal.

## Signature

```csharp
Microsoft.Maui.Maps.MapSpan! WithZoom(double zoomFactor)
```

## Parameters

| Parameter | Description |
|---|---|
| `left` | The first span. |
| `right` | The second span. |
| `zoomFactor` | The zoom factor. Values greater than 1 zoom in, values less than 1 zoom out. |

## Returns

`true` if the spans are not equal; otherwise, `false`.
