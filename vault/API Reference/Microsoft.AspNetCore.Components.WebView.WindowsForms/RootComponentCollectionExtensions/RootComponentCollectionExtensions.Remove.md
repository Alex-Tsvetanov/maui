# RootComponentCollectionExtensions.Remove

> [!abstract] Method of [[RootComponentCollectionExtensions|RootComponentCollectionExtensions]]
> Namespace: `Microsoft.AspNetCore.Components.WebView.WindowsForms`

Removes the component associated with the specified `selector` from the collection specified by `components` .

```csharp
void static Remove(this Microsoft.AspNetCore.Components.WebView.WindowsForms.RootComponentsCollection! components, string! selector)
```

## Parameters

| Parameter | Description |
|---|---|
| `components` | The collection from which the component associated with the selector should be removed. |
| `selector` | The selector associated with the component to be removed. |
