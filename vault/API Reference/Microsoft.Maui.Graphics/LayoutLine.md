# LayoutLine

> [!abstract] Class in `Microsoft.Maui.Graphics`
> Full name: `Microsoft.Maui.Graphics.LayoutLine`

## Parameters

| Parameter | Description |
|---|---|
| `aPoint` | The position of the line. |
| `aTextual` | The text attributes to use for rendering the line. |
| `aText` | The text content of the line. |
| `aAscent` | The ascent of the line (distance from baseline to the top of the tallest glyph). |
| `aDescent` | The descent of the line (distance from baseline to the bottom of the deepest glyph). |
| `aLeading` | The leading of the line (extra space between lines). |
