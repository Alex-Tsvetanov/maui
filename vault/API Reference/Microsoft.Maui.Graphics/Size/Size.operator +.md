# Size.operator +

> [!abstract] Operator of [[Size|Size]]
> Namespace: `Microsoft.Maui.Graphics`

Adds two sizes together by adding their width and height components.

## Signature

```csharp
Microsoft.Maui.Graphics.Size static operator +(Microsoft.Maui.Graphics.Size s1, Microsoft.Maui.Graphics.Size s2)
```

## Returns

A new size with the width and height being the sum of the two sizes.

## Parameters

| Parameter | Description |
|---|---|
| `s1` | The first size to add. |
| `s2` | The second size to add. |
