# ICanvas.ClipRectangle

> [!abstract] Method of [[ICanvas|ICanvas]]
> Namespace: `Microsoft.Maui.Graphics`

Clips an object so that only the area that's within the region of the rectangle will be visible.

## Signature

```csharp
void ClipRectangle(float x, float y, float width, float height)
```

## Parameters

| Parameter | Description |
|---|---|
| `x` | Starting x coordinate of the rectangle. |
| `y` | Starting y coordinate of the rectangle. |
| `width` | Width of the rectangle. |
| `height` | Height of the rectangle. |
