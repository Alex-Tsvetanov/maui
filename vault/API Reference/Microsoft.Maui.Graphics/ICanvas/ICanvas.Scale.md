# ICanvas.Scale

> [!abstract] Method of [[ICanvas|ICanvas]]
> Namespace: `Microsoft.Maui.Graphics`

Changes the size of a graphical object by scaling it.

## Signature

```csharp
void Scale(float sx, float sy)
```

## Parameters

| Parameter | Description |
|---|---|
| `sx` | Value for horizontal scaling. |
| `sy` | Value for vertical scaling. |

## Remarks

Can cause starting coordinates to move when an object is made larger.
