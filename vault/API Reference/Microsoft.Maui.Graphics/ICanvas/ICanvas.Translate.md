# ICanvas.Translate

> [!abstract] Method of [[ICanvas|ICanvas]]
> Namespace: `Microsoft.Maui.Graphics`

Shifts a graphical object in horizontal and vertical directions.

## Signature

```csharp
void Translate(float tx, float ty)
```

## Parameters

| Parameter | Description |
|---|---|
| `tx` | Horizontal shift. Negative values move the object to the left, while positive values move it to the right. |
| `ty` | Vertical shift. Negative values move the object down, while positive values move it up. |
