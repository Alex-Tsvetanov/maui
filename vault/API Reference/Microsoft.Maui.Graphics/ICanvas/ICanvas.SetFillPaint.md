# ICanvas.SetFillPaint

> [!abstract] Method of [[ICanvas|ICanvas]]

```csharp
void SetFillPaint(Microsoft.Maui.Graphics.Paint paint, Microsoft.Maui.Graphics.RectF rectangle)
```

## Parameters

| Parameter | Description |
|---|---|
| `paint` | Paint to set as fill |
| `rectangle` | Rectangle to apply a gradient on if the `paint` supports it. |
