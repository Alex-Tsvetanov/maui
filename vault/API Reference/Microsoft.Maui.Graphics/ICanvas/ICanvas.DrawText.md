# ICanvas.DrawText

> [!abstract] Method of [[ICanvas|ICanvas]]
> Namespace: `Microsoft.Maui.Graphics`

Draws attributed text within a bounding box onto the canvas.

## Signature

```csharp
void DrawText(Microsoft.Maui.Graphics.Text.IAttributedText value, float x, float y, float width, float height)
```

## Parameters

| Parameter | Description |
|---|---|
| `value` | Attributed text to be displayed. |
| `x` | Starting x coordinate of the bounding box. |
| `y` | Starting y coordinate of the bounding box. |
| `width` | Width of the bounding box. |
| `height` | Height of the bounding box. |
