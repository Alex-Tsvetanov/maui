# ICanvas.SetShadow

> [!abstract] Method of [[ICanvas|ICanvas]]
> Namespace: `Microsoft.Maui.Graphics`

Adds a shadow to a graphical object.

## Signature

```csharp
void SetShadow(Microsoft.Maui.Graphics.SizeF offset, float blur, Microsoft.Maui.Graphics.Color color)
```

## Parameters

| Parameter | Description |
|---|---|
| `offset` | Represents the position of a light source that creates the shadow. |
| `blur` | Amount of blur to apply to the shadow. |
| `color` | Color of the shadow. |
