# MediaPickerOptions.SelectionLimit

> [!abstract] Property of [[MediaPickerOptions|MediaPickerOptions]]
> Namespace: `Microsoft.Maui.Media`

Gets or sets the maximum number of items that can be selected. Default value is 1.

## Signature

```csharp
int SelectionLimit { get; set; }
```

## Remarks

A value of 0 means no limit.
