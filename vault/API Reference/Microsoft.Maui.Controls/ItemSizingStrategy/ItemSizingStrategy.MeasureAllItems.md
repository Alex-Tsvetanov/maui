# ItemSizingStrategy.MeasureAllItems

> [!abstract] Field of [[ItemSizingStrategy|ItemSizingStrategy]]
> Namespace: `Microsoft.Maui.Controls`

Each item is measured individually to determine its size. This provides the most accurate sizing but has a performance cost for large collections.
