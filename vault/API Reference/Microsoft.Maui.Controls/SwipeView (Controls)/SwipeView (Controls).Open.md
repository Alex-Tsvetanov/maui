# SwipeView (Controls).Open

> [!abstract] Method of [[SwipeView (Controls)|SwipeView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Opens the SwipeView to reveal the specified swipe item.

## Signature

```csharp
void Open(Microsoft.Maui.OpenSwipeItem openSwipeItem, bool animated = true)
```

## Parameters

| Parameter | Description |
|---|---|
| `openSwipeItem` | Specifies which side of the SwipeView to open (Left, Right, Top, or Bottom). |
| `animated` | Whether to animate the opening transition. Defaults to true. |
