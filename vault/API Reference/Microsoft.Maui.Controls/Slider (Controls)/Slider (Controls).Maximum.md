# Slider (Controls).Maximum

> [!abstract] Property of [[Slider (Controls)|Slider (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the maximum value of the slider. This is a bindable property.

## Signature

```csharp
double Maximum { get; set; }
```

## Remarks

Changing this value will automatically clamp the `Value` to be within the new range.
