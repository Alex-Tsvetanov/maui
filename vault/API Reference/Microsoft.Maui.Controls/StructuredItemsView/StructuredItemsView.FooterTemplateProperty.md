# StructuredItemsView.FooterTemplateProperty

> [!abstract] Field of [[StructuredItemsView|StructuredItemsView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the object to display as the footer of the items view.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly FooterTemplateProperty
```

## Remarks

The footer appears after all items in the collection. If `FooterTemplate` is set, it is used to render the footer; otherwise, the object's string representation is displayed.
