# StructuredItemsView.Header

> [!abstract] Property of [[StructuredItemsView|StructuredItemsView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the object to display as the header of the items view.

## Signature

```csharp
object Header { get; set; }
```

## Remarks

The header appears before all items in the collection. If `HeaderTemplate` is set, it is used to render the header; otherwise, the object's string representation is displayed.
