# ListView (Controls).SeparatorColor

> [!abstract] Property of [[ListView (Controls)|ListView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the color of the bar that separates list items.

## Signature

```csharp
Microsoft.Maui.Graphics.Color SeparatorColor { get; set; }
```

## Remarks

The default value is Color.Default . This property has no effect if `SeparatorVisibility` is `false`.
