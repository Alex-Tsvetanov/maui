# Slider (Controls)

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.Slider`

## Remarks

The `Slider` control allows users to select a numeric value by moving a thumb along a track. Use the `Minimum` and `Maximum` properties to define the range, and the `Value` property to get or set the current selection.
