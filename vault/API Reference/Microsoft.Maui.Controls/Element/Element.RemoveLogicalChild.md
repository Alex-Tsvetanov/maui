# Element.RemoveLogicalChild

> [!abstract] Method of [[Element|Element]]
> Namespace: `Microsoft.Maui.Controls`

Removes the first occurrence of a specific `Element` from the logical children.

## Signature

```csharp
bool RemoveLogicalChild(Microsoft.Maui.Controls.Element element)
```

## Parameters

| Parameter | Description |
|---|---|
| `element` | The `Element` to remove. |

## Returns

true if item was successfully removed from the logical children; otherwise, false. This method also returns false if `Element` is not found.
