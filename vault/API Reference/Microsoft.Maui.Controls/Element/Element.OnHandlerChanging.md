# Element.OnHandlerChanging

> [!abstract] Method of [[Element|Element]]
> Namespace: `Microsoft.Maui.Controls`

When overridden in a derived class, should raise the `HandlerChanging` event.

## Signature

```csharp
void virtual OnHandlerChanging(Microsoft.Maui.Controls.HandlerChangingEventArgs args)
```

## Parameters

| Parameter | Description |
|---|---|
| `args` | Provides data for the `HandlerChanging` event. |

## Remarks

It is the implementor's responsibility to raise the `HandlerChanging` event.
