# FlyoutPage (Controls).ShouldShowToolbarButton

> [!abstract] Method of [[FlyoutPage (Controls)|FlyoutPage (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Returns a value that indicates whether the toolbar should display a button to toggle the flyout.

## Signature

```csharp
bool virtual ShouldShowToolbarButton()
```

## Returns

`true` if the toolbar button should be shown; otherwise, `false`.
