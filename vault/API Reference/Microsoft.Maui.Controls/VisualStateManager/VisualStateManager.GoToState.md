# VisualStateManager.GoToState

> [!abstract] Method of [[VisualStateManager|VisualStateManager]]
> Namespace: `Microsoft.Maui.Controls`

Transitions the `visualElement` to the specified visual state.

## Signature

```csharp
bool static GoToState(Microsoft.Maui.Controls.VisualElement visualElement, string name)
```

## Parameters

| Parameter | Description |
|---|---|
| `visualElement` | The visual element to transition. |
| `name` | The name of the visual state to transition to. |

## Returns

`true` if the transition was successful; otherwise, `false`.
