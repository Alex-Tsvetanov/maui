# DisplayRotationStateTrigger.RotationProperty

> [!abstract] Field of [[DisplayRotationStateTrigger|DisplayRotationStateTrigger]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the display rotation that will activate this trigger.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty! static readonly RotationProperty
```

## Remarks

The trigger will be active when the device's current display rotation matches this property value. Possible values are: `Rotation0` - Device is in its natural position (0 degrees) `Rotation90` - Device is rotated 90 degrees `Rotation180` - Device is rotated 180 degrees (upside down) `Rotation270` - Device is rotated 270 degrees `Unknown` - Device rotation is unknown
