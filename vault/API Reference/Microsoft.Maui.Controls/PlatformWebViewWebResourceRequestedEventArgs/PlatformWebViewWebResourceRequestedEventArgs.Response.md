# PlatformWebViewWebResourceRequestedEventArgs.Response

> [!abstract] Property of [[PlatformWebViewWebResourceRequestedEventArgs|PlatformWebViewWebResourceRequestedEventArgs]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the native response to return to the web view. This property must be set to a valid response if the `Handled` property is set to true. This is only available on Android.

## Signature

