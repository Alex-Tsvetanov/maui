# ResourceDictionary.ContainsKey

> [!abstract] Method of [[ResourceDictionary|ResourceDictionary]]
> Namespace: `Microsoft.Maui.Controls`

Returns whether the dictionary contains a key-value pair identified by the specified key.

## Signature

```csharp
bool ContainsKey(string key)
```

## Parameters

| Parameter | Description |
|---|---|
| `key` | The identifier to search for. |

## Returns

`true` if the key exists in the immediate dictionary; otherwise, `false`.
