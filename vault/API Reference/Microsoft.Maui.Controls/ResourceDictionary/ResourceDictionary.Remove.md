# ResourceDictionary.Remove

> [!abstract] Method of [[ResourceDictionary|ResourceDictionary]]
> Namespace: `Microsoft.Maui.Controls`

Removes the key-value pair identified by the specified key.

## Signature

```csharp
bool Remove(string key)
```

## Parameters

| Parameter | Description |
|---|---|
| `key` | The identifier of the item to remove. |

## Returns

`true` if the key existed and was removed; otherwise, `false`.
