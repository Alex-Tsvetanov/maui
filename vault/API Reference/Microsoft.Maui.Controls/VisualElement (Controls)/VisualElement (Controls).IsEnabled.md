# VisualElement (Controls).IsEnabled

> [!abstract] Property of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a value indicating whether this element is enabled in the user interface. This is a bindable property.

## Signature

```csharp
bool IsEnabled { get; set; }
```

## Remarks

The default value is `true`. Elements that are not enabled will not receive focus or respond to input events.
