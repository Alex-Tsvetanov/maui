# VisualElement (Controls).OnMeasure

> [!abstract] Method of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Method that is called when a layout measurement happens.

## Signature

```csharp
Microsoft.Maui.SizeRequest virtual OnMeasure(double widthConstraint, double heightConstraint)
```

## Parameters

| Parameter | Description |
|---|---|
| `widthConstraint` | The width constraint to request. |
| `heightConstraint` | The height constraint to request. |

## Returns

The requested size that the element requires in order to be displayed on the device.
