# VisualElement (Controls).OnSizeAllocated

> [!abstract] Method of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Method that is called when the size of the element is set during a layout cycle. Implement this method to add class handling for this event.

## Signature

```csharp
void virtual OnSizeAllocated(double width, double height)
```

## Parameters

| Parameter | Description |
|---|---|
| `width` | The new width of the element. |
| `height` | The new height of the element. |
