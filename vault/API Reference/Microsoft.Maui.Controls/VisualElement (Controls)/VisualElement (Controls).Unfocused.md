# VisualElement (Controls).Unfocused

> [!abstract] Event of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Occurs when this element is unfocused.

## Signature

```csharp
System.EventHandler<Microsoft.Maui.Controls.FocusEventArgs> Unfocused
```

## Remarks

This event is not triggered when the element does not currently have focus.
