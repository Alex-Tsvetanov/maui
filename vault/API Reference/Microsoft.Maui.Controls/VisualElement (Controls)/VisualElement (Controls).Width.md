# VisualElement (Controls).Width

> [!abstract] Property of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets the current width of this element in device-independent units. This is a read-only bindable property.

## Signature

```csharp
double Width { get; }
```

## Remarks

The width value of an element is set during the layout cycle. Device-independent units (DIUs) provide a consistent unit of measurement across different screen densities. One device-independent unit equals one pixel on a 96-DPI display.
