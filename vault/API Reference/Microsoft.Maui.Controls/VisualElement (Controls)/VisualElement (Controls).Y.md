# VisualElement (Controls).Y

> [!abstract] Property of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets the current Y position of this element in device-independent units. This is a read-only bindable property.

## Signature

```csharp
double Y { get; }
```

## Remarks

The position of an element is set during layout. Device-independent units (DIUs) provide a consistent unit of measurement across different screen densities. One device-independent unit equals one pixel on a 96-DPI display.
