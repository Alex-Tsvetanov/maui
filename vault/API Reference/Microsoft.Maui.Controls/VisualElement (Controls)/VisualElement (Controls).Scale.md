# VisualElement (Controls).Scale

> [!abstract] Property of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the scale factor applied to the element. This is a bindable property.

## Signature

```csharp
double Scale { get; set; }
```

## Remarks

Default value is 1.0. `Scale` is applied relative to `AnchorX` and `AnchorY`.
