# VisualElement (Controls).IsFocused

> [!abstract] Property of [[VisualElement (Controls)|VisualElement (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets a value indicating whether this element is focused currently. This is a bindable property.

## Signature

```csharp
bool IsFocused { get; }
```

## Remarks

Applications may have multiple focuses depending on the implementation of the underlying platform. Menus and modals in particular may leave multiple items with focus.
