# SearchBar (Controls).SearchButtonPressed

> [!abstract] Event of [[SearchBar (Controls)|SearchBar (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Determines what the return key on the on-screen keyboard should look like. This is a bindable property.

## Signature

```csharp
System.EventHandler SearchButtonPressed
```

## Remarks

This command is executed when the user presses the search button on the keyboard or when `OnSearchButtonPressed` is called. The `SearchCommandParameter` is passed as the command parameter.
