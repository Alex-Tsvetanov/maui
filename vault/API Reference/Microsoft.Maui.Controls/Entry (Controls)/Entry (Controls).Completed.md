# Entry (Controls).Completed

> [!abstract] Event of [[Entry (Controls)|Entry (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the horizontal text alignment. This is a bindable property.

## Signature

```csharp
System.EventHandler Completed
```

## Remarks

Toggling this value does not reset the contents of the entry, therefore it is advisable to be careful about setting `IsPassword` to false, as it may contain sensitive information.
