> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.IndicatorView`

## Remarks

`IndicatorView` is commonly used with `CarouselView` to display dots or other shapes indicating the current position and total number of items. The indicators automatically update when the position changes.
