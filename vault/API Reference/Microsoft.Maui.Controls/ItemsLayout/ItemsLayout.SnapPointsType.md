# ItemsLayout.SnapPointsType

> [!abstract] Property of [[ItemsLayout|ItemsLayout]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the snap points behavior when scrolling.

## Signature

```csharp
Microsoft.Maui.Controls.SnapPointsType SnapPointsType { get; set; }
```

## Remarks

Snap points cause scrolling to "snap" to specific item positions, creating a paging-like effect. Set this to `Mandatory` or `MandatorySingle` to enable snapping behavior.
