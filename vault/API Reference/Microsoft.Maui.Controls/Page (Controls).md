## Remarks

is primarily a base class for more useful derived types. Objects that are derived from the `Page` class are most prominently used as the top level UI element in .NET MAUI applications. In addition to their role as the main pages of applications, `Page` objects and their descendants can be used with navigation classes, such as `NavigationPage` or `FlyoutPage`, among others, to provide rich user experiences that conform to the expected behaviors on each platform.
