# IndicatorView.Position

> [!abstract] Property of [[IndicatorView|IndicatorView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the index of the currently selected indicator.

## Signature

```csharp
int Position { get; set; }
```

## Remarks

This property is typically bound to a `Position` property to keep the indicator view synchronized with the carousel position.
