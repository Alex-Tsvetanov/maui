# IndicatorView.IndicatorLayout

> [!abstract] Property of [[IndicatorView|IndicatorView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the layout that arranges the indicator views.

## Signature

```csharp
Microsoft.Maui.Controls.IBindableLayout IndicatorLayout { get; set; }
```

## Remarks

This property is set automatically when `IndicatorTemplate` is specified. Use this as the content property when defining custom indicator layouts in XAML.
