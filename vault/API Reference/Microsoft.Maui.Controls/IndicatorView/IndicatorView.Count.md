# IndicatorView.Count

> [!abstract] Property of [[IndicatorView|IndicatorView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the total number of indicators to display.

## Signature

```csharp
int Count { get; set; }
```

## Remarks

This is automatically set when `ItemsSource` is provided. You can also set this manually when not using an items source.
