# IndicatorView.HideSingle

> [!abstract] Property of [[IndicatorView|IndicatorView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a value indicating whether the indicator view is hidden when only one item exists.

## Signature

```csharp
bool HideSingle { get; set; }
```

## Remarks

When enabled and `Count` is 1 or less, the indicator view will not be displayed.
