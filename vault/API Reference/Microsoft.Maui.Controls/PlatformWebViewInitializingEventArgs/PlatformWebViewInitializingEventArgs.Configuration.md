# PlatformWebViewInitializingEventArgs.Configuration

> [!abstract] Property of [[PlatformWebViewInitializingEventArgs|PlatformWebViewInitializingEventArgs]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the relative path to the folder that contains a custom version of WebView2 Runtime.

## Signature

```csharp
WebKit.WKWebViewConfiguration! Configuration { get; }
```

## Remarks

To use a fixed version of the WebView2 Runtime, set this property to the folder path that contains the fixed version of the WebView2 Runtime.
