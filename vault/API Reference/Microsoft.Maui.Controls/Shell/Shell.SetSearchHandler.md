# Shell.SetSearchHandler

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the handler responsible for implementing the integrated search functionality for when the given `obj` is active. Enabling this property results in a search box being added at the top of the page.

## Signature

```csharp
void static SetSearchHandler(Microsoft.Maui.Controls.BindableObject obj, Microsoft.Maui.Controls.SearchHandler handler)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies the Shell search functionality. |
| `handler` | Defines the integrated search functionality. |
