# Shell.SetBackgroundColor

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the background color in the Shell chrome. The color won't fill in behind the Shell content.

## Signature

```csharp
void static SetBackgroundColor(Microsoft.Maui.Controls.BindableObject obj, Microsoft.Maui.Graphics.Color value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object to which the background color is set. |
| `value` | The background color for the Shell chrome. |
