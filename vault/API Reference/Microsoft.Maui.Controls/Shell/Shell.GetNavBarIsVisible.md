# Shell.GetNavBarIsVisible

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Gets a value indicating if the navigation bar is visible when when the given `obj` is active.

## Signature

```csharp
bool static GetNavBarIsVisible(Microsoft.Maui.Controls.BindableObject obj)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that that gets the navigation bar visibility. |

## Returns

`true` if the navigation bar is visible; otherwise, `false`.
