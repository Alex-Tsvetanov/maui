# Shell.SetTabBarForegroundColor

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the foreground color for the tab bar. If the property is unset, the ForegroundColor property value is used.

## Signature

```csharp
void static SetTabBarForegroundColor(Microsoft.Maui.Controls.BindableObject obj, Microsoft.Maui.Graphics.Color value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object to which the color is set. |
| `value` | The foreground color for the tab bar. |
