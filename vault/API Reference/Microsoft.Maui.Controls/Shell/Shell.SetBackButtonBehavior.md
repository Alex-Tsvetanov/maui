# Shell.SetBackButtonBehavior

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the back button behavior when the given `obj` is presented.

## Signature

```csharp
void static SetBackButtonBehavior(Microsoft.Maui.Controls.BindableObject obj, Microsoft.Maui.Controls.BackButtonBehavior behavior)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The page that dictates the Shell's back button behavior when active. |
| `behavior` | The back button behavior. |

## Remarks

If the `obj` is not a page, this property won't do anything.
