# Shell.SetFlyoutWidth

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the width of the flyout when the given `obj` is active. This enables scenarios such as expanding the flyout across the entire screen.

## Signature

```csharp
void static SetFlyoutWidth(Microsoft.Maui.Controls.BindableObject obj, double value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies the width of the flyout. |
| `value` | Defines the width of the flyout. |
