# Shell.SetFlyoutHeight

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Sets the height of the flyout.

## Signature

```csharp
void static SetFlyoutHeight(Microsoft.Maui.Controls.BindableObject obj, double value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies the height of the flyout. |
| `value` | Defines the height of the flyout. |

## Remarks

The height of the flyout can be customized by setting the Shell.FlyoutHeight attached properties to double value. This enables scenarios such as reducing the height of the flyout so that it doesn't obscure the tab bar.
