# Shell.GetNavBarVisibilityAnimationEnabled

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Gets a value indicating whether the navigation bar visibility change is animated for the given `obj`.

## Signature

```csharp
bool static GetNavBarVisibilityAnimationEnabled(Microsoft.Maui.Controls.BindableObject obj)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that retrieves the animation setting. |

## Returns

`true` if the animation is enabled; otherwise, `false`.
