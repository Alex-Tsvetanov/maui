# Shell.SetNavBarHasShadow

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Controls whether the navigation bar has a shadow when the given `obj` is active. By default the value of the property is `true` on Android, and `false` on other platforms.

## Signature

```csharp
void static SetNavBarHasShadow(Microsoft.Maui.Controls.BindableObject obj, bool value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies if the navigation bar has a shadow. |
| `value` | Manages if the navigation bar has a shadow. |
