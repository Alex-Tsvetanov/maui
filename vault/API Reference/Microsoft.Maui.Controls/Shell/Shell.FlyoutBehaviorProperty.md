# Shell.FlyoutBehaviorProperty

> [!abstract] Field of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Manages the behavior used to open the flyout.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly FlyoutBehaviorProperty
```

## Remarks

The flyout can be accessed through the hamburger icon or by swiping from the side of the screen. This behavior can be changed by setting the property.
