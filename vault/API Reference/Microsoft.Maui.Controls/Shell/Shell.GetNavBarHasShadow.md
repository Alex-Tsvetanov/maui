# Shell.GetNavBarHasShadow

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Gets a value that represents if the navigation bar has a shadow when the given `obj` is active.

## Signature

```csharp
bool static GetNavBarHasShadow(Microsoft.Maui.Controls.BindableObject obj)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies if the navigation bar has a shadow. |

## Returns

`true` if the navigation bar has a shadow when `obj` is presented, otherwise, `false`.
