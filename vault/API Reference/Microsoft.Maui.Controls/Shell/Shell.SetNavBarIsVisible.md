# Shell.SetNavBarIsVisible

> [!abstract] Method of [[Shell|Shell]]
> Namespace: `Microsoft.Maui.Controls`

Controls if the navigation bar is visible when the given `obj` is presented. By default the value of the property is `true`.

## Signature

```csharp
void static SetNavBarIsVisible(Microsoft.Maui.Controls.BindableObject obj, bool value)
```

## Parameters

| Parameter | Description |
|---|---|
| `obj` | The object that modifies the navigation bar visibility. |
| `value` | `true` to set the navigation bar as visible; otherwise, `false`. |
