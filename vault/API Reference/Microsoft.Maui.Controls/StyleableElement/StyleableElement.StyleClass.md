# StyleableElement.StyleClass

> [!abstract] Property of [[StyleableElement|StyleableElement]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the style classes for the element.

## Signature

```csharp
System.Collections.Generic.IList<string!>! StyleClass { get; set; }
```

## Remarks

Equiavalent to `@class`. Style classes enable multiple styles to be applied to a control, without resorting to style inheritance.
