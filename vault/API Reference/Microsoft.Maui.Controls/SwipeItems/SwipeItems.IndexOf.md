# SwipeItems.IndexOf

> [!abstract] Method of [[SwipeItems|SwipeItems]]

Gets the index of a specified location object.

## Signature

```csharp
int IndexOf(Microsoft.Maui.Controls.ISwipeItem item)
```

## Returns

The index of the specified location, if the location was not found this will return -1 .

## Parameters

| Parameter | Description |
|---|---|
| `item` | The location object of which to determine the index. |
