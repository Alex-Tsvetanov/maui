# DataTemplateSelector.SelectTemplate

> [!abstract] Method of [[DataTemplateSelector|DataTemplateSelector]]
> Namespace: `Microsoft.Maui.Controls`

Returns a `DataTemplate` for the specified item and container.

## Signature

```csharp
Microsoft.Maui.Controls.DataTemplate SelectTemplate(object item, Microsoft.Maui.Controls.BindableObject container)
```

## Parameters

| Parameter | Description |
|---|---|
| `item` | The data object for which to select a template. |
| `container` | The bindable object that will display the templated item. |

## Returns

The selected `DataTemplate`.
