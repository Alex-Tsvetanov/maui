# Layout (Controls).IndexOf

> [!abstract] Method of [[Layout (Controls)|Layout (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets the index of a specified child view.

## Signature

```csharp
int IndexOf(Microsoft.Maui.IView item)
```

## Parameters

| Parameter | Description |
|---|---|
| `item` | The child view of which to determine the index. |

## Returns

The index of the specified view, if the view was not found this will return -1 .
