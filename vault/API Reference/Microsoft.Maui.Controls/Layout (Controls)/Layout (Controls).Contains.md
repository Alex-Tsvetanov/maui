# Layout (Controls).Contains

> [!abstract] Method of [[Layout (Controls)|Layout (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Determines if the specified child view is contained in this layout.

## Signature

```csharp
bool Contains(Microsoft.Maui.IView item)
```

## Parameters

| Parameter | Description |
|---|---|
| `item` | The child view for which to determine if it is contained in this layout. |

## Returns

`true` if `item` exists in this layout, otherwise `false`.
