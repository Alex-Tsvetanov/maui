# Layout (Controls).SafeAreaEdgesProperty

> [!abstract] Field of [[Layout (Controls)|Layout (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the inner padding of the layout. The default value is a `Thickness` with all values set to 0.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly SafeAreaEdgesProperty
```

## Remarks

The padding is the space between the bounds of a layout and the bounding region into which its children should be arranged into.
