# Layout (Controls).OnAdd

> [!abstract] Method of [[Layout (Controls)|Layout (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Invoked when `Add` is called and notifies the handler associated to this layout.

## Signature

```csharp
void virtual OnAdd(int index, Microsoft.Maui.IView view)
```

## Parameters

| Parameter | Description |
|---|---|
| `index` | The index at which the child view was inserted. |
| `view` | The child view which was inserted. |
