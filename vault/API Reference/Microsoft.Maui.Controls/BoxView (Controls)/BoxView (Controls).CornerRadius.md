# BoxView (Controls).CornerRadius

> [!abstract] Property of [[BoxView (Controls)|BoxView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the corner radius for the box view.

## Signature

```csharp
Microsoft.Maui.CornerRadius CornerRadius { get; set; }
```

## Remarks

When specifying corner radii, the order of values is top left, top right, bottom left, and bottom right.
