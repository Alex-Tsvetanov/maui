# AutomationProperties.SetLabeledBy

> [!abstract] Method of [[AutomationProperties|AutomationProperties]]
> Namespace: `Microsoft.Maui.Controls`

Sets another element, such as a `Label` as the label for `bindable`.

## Signature

```csharp
void static SetLabeledBy(Microsoft.Maui.Controls.BindableObject bindable, Microsoft.Maui.Controls.VisualElement value)
```

## Parameters

| Parameter | Description |
|---|---|
| `bindable` | The object whose label to set. |
| `value` | The visual element that will name `bindable`, or `null` to make `bindable` its own label. |
