# DataPackagePropertySet.TryGetValue

> [!abstract] Method of [[DataPackagePropertySet|DataPackagePropertySet]]
> Namespace: `Microsoft.Maui.Controls`

Gets the value associated with the specified key.

## Signature

```csharp
bool TryGetValue(string key, out object value)
```

## Parameters

| Parameter | Description |
|---|---|
| `key` | The key of the value to get. |
| `value` | When this method returns, contains the value if the key was found; otherwise, the default value. |
