# Grid (Controls).SetRow

> [!abstract] Method of [[Grid (Controls)|Grid (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

## Signatures

```csharp
void SetRow(Microsoft.Maui.IView view, int row)
void static SetRow(Microsoft.Maui.Controls.BindableObject bindable, int value)
```

## Parameters

| Parameter | Description |
|---|---|
| `bindable` | A child element of this Grid to move to a different row. |
| `value` | The row in which to place the child element. |
