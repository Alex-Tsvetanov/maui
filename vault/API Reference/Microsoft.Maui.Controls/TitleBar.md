# TitleBar

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.TitleBar`

A `View` control that provides title bar functionality for a window. The standard title bar height is 32px, but can be set to a larger value. The title bar can also be hidden by setting the `IsVisible` property, which will cause the window content to be displayed in the title bar region.
