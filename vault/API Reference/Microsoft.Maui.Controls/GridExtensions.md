# GridExtensions

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.GridExtensions`

Provides extension methods for adding and positioning children within a Grid.

## Methods

| Name | Summary |
|---|---|
| [[GridExtensions.Add\|Add]] | Adds an `IView` to the `Grid` at the specified column and row with a row span of 1 and a column span of 1. |
| [[GridExtensions.AddWithSpan\|AddWithSpan]] | Adds an `IView` to the the `Grid` at the specified row and column with the specified row and column spans. |
