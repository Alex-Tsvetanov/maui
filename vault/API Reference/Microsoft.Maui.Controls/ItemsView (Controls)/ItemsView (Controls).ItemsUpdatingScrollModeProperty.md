# ItemsView (Controls).ItemsUpdatingScrollModeProperty

> [!abstract] Field of [[ItemsView (Controls)|ItemsView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the `DataTemplate` used to render each item in the collection.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly ItemsUpdatingScrollModeProperty
```

## Remarks

The template's binding context is set to each item in the `ItemsSource`. For dynamic template selection based on item data, use a `DataTemplateSelector` instead.
