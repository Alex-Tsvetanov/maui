# ItemsView (Controls).EmptyViewTemplate

> [!abstract] Property of [[ItemsView (Controls)|ItemsView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the `DataTemplate` used to render the `EmptyView`.

## Signature

```csharp
Microsoft.Maui.Controls.DataTemplate EmptyViewTemplate { get; set; }
```

## Remarks

The template's binding context is set to the `EmptyView` object. This allows for rich, custom layouts to be displayed when the collection is empty.
