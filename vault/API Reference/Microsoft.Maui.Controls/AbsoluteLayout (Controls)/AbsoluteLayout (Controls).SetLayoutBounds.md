# AbsoluteLayout (Controls).SetLayoutBounds

> [!abstract] Method of [[AbsoluteLayout (Controls)|AbsoluteLayout (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Sets the layout bounds of a view that will be used to interpret the layout bounds set on it when it is added to the layout.

## Signatures

```csharp
void SetLayoutBounds(Microsoft.Maui.IView view, Microsoft.Maui.Graphics.Rect bounds)
void static SetLayoutBounds(Microsoft.Maui.Controls.BindableObject bindable, Microsoft.Maui.Graphics.Rect bounds)
```

## Parameters

| Parameter | Description |
|---|---|
| `bindable` | The bindable object to set the layout bounds for. |
| `bounds` | The bounds to set on the given bindable object. |
