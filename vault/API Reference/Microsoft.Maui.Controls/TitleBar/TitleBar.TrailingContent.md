# TitleBar.TrailingContent

> [!abstract] Property of [[TitleBar|TitleBar]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a `View` control that represents the trailing content. The trailing content is aligned to the right or left of the title bar, depending on the `FlowDirection`. Views set here will be allocated as much space as they require. Views set here will block all input to the title bar region and handle input directly.
