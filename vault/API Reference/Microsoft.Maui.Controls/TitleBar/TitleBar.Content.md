# TitleBar.Content

> [!abstract] Property of [[TitleBar|TitleBar]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a `View` control that represents the content. This content is centered in the title bar, and is allocated the remaining space between the leading and trailing content. Views set here will block all input to the title bar region and handle input directly.
