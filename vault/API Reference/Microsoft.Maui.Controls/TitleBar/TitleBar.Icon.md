# TitleBar.Icon

> [!abstract] Property of [[TitleBar|TitleBar]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets an optional icon image of the title bar. Icon images should be 16x16 pixels in size. Setting this property to an empty value will hide the icon.
