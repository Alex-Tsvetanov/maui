# Button (Controls).Text

> [!abstract] Property of [[Button (Controls)|Button (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the text displayed as the content of the button. The default value is `null`. This is a bindable property.

## Signature

```csharp
string Text { get; set; }
```

## Remarks

Changing the text of a button will trigger a layout cycle.
