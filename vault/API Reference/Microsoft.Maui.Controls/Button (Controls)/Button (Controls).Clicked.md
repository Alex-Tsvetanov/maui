# Button (Controls).Clicked

> [!abstract] Event of [[Button (Controls)|Button (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a value that indicates whether the font for the text of this button is bold, italic, or neither. This is a bindable property.

## Signature

```csharp
System.EventHandler Clicked
```

## Remarks

Typically this should always be enabled for accessibility reasons.
