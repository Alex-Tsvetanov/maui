# CompressedLayout.GetIsHeadless

> [!abstract] Method of [[CompressedLayout|CompressedLayout]]
> Namespace: `Microsoft.Maui.Controls`

Gets a Boolean value that tells whether layout compression is enabled for the specified bindable object.

## Signature

```csharp
bool static GetIsHeadless(Microsoft.Maui.Controls.BindableObject bindable)
```

## Parameters

| Parameter | Description |
|---|---|
| `bindable` | The `BindableObject` whose status to check. |

## Returns

`true` if layout compression is enabled for `bindable`. Otherwise, returns `false`.
