# Switch (Controls)

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.Switch`

## Remarks

A `Switch` is a UI element that can be toggled between on and off states. Use the `IsToggled` property to determine or set the current state.
