# AnimationExtensions.AnimationIsRunning

> [!abstract] Method of [[AnimationExtensions|AnimationExtensions]]
> Namespace: `Microsoft.Maui.Controls`

Returns a Boolean value that indicates whether or not the animation that is specified by `handle` is running.

## Signature

```csharp
bool static AnimationIsRunning(this Microsoft.Maui.Controls.IAnimatable self, string handle)
```

## Parameters

| Parameter | Description |
|---|---|
| `self` | The object on which this method will be run. |
| `handle` | An animation key that must be unique among its sibling and parent animations for the duration of the animation. |
