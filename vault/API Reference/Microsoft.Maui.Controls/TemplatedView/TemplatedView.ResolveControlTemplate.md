# TemplatedView.ResolveControlTemplate

> [!abstract] Method of [[TemplatedView|TemplatedView]]
> Namespace: `Microsoft.Maui.Controls`

Resolves and returns the `ControlTemplate` associated with this instance.

## Signature

```csharp
Microsoft.Maui.Controls.ControlTemplate virtual ResolveControlTemplate()
```

## Returns

The `ControlTemplate` currently assigned to this instance. If no template is assigned, this method returns `null`.
