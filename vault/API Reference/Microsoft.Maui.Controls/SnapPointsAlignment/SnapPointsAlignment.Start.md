# SnapPointsAlignment.Start

> [!abstract] Field of [[SnapPointsAlignment|SnapPointsAlignment]]
> Namespace: `Microsoft.Maui.Controls`

Items snap to align with the start of the scrollable area. For vertical scrolling, items align to the top. For horizontal scrolling, items align to the left (or right in RTL).
