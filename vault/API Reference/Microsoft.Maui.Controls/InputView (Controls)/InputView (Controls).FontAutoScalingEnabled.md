# InputView (Controls).FontAutoScalingEnabled

> [!abstract] Property of [[InputView (Controls)|InputView (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Determines whether or not the font of this entry should scale automatically according to the operating system settings. Default value is `true`. This is a bindable property.

## Signature

```csharp
bool FontAutoScalingEnabled { get; set; }
```

## Remarks

Typically this should always be enabled for accessibility reasons.
