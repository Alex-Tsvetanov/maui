# GroupableItemsView.GroupHeaderTemplateProperty

> [!abstract] Field of [[GroupableItemsView|GroupableItemsView]]

Gets or sets a value indicating whether items should be displayed in groups.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly GroupHeaderTemplateProperty
```

## Remarks

When enabled, the `ItemsSource` is expected to be a collection of groups, where each group is itself a collection of items.
