# CarouselView.IsDragging

> [!abstract] Property of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets a value indicating whether the user is currently dragging the carousel.

## Signature

```csharp
bool IsDragging { get; }
```

## Remarks

This property is set to `true` when the user begins a drag gesture and returns to `false` when the gesture completes or is cancelled.
