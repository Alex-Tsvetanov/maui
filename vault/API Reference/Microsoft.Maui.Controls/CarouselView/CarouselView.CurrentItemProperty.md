# CarouselView.CurrentItemProperty

> [!abstract] Field of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a value indicating whether scrolling between items is animated.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly CurrentItemProperty
```

## Remarks

When `true`, programmatic changes to `Position` or `CurrentItem` will animate the transition. When `false`, the carousel jumps instantly to the new position.
