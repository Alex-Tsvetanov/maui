# CarouselView.ItemsLayout

> [!abstract] Property of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the layout used to arrange items in the carousel.

## Signature

```csharp
Microsoft.Maui.Controls.LinearItemsLayout ItemsLayout { get; set; }
```

## Remarks

The items layout determines whether items are arranged horizontally or vertically, and controls snap behavior through `SnapPointsType` and `SnapPointsAlignment`.
