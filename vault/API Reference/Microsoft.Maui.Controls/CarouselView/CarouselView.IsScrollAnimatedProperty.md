# CarouselView.IsScrollAnimatedProperty

> [!abstract] Field of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets a value indicating whether swipe gestures are enabled for navigation.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly IsScrollAnimatedProperty
```

## Remarks

When disabled, users cannot navigate between items using swipe gestures. Programmatic navigation using `Position` or `CurrentItem` still works when this is disabled.
