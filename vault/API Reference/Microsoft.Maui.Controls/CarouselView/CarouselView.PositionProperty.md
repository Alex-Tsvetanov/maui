# CarouselView.PositionProperty

> [!abstract] Field of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the currently displayed item in the carousel.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly PositionProperty
```

## Remarks

This property is bindable and supports two-way binding. Setting this property programmatically will scroll the carousel to display the specified item.
