# CarouselView.ItemsLayoutProperty

> [!abstract] Field of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the index of the currently displayed item in the carousel.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly ItemsLayoutProperty
```

## Remarks

This property is bindable and supports two-way binding. Setting this property programmatically will scroll the carousel to display the item at the specified index.
