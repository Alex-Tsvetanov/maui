# CarouselView.VisibleViewsProperty

> [!abstract] Field of [[CarouselView|CarouselView]]
> Namespace: `Microsoft.Maui.Controls`

Gets or sets the amount of space to reserve on each side of the current item to show a peek of adjacent items.

## Signature

```csharp
Microsoft.Maui.Controls.BindableProperty static readonly VisibleViewsProperty
```

## Remarks

Use this property to show a preview of adjacent items on either side of the current item. This helps users understand that more items are available by swiping.
