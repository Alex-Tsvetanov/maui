# Border

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.Border`

## Remarks

Border provides a way to add visual decoration around any content. You can customize the stroke (border), background, shape, padding, and more to create visually rich containers.
