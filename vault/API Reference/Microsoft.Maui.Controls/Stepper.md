# Stepper

> [!abstract] Class in `Microsoft.Maui.Controls`
> Full name: `Microsoft.Maui.Controls.Stepper`

## Remarks

The `Stepper` provides buttons to increase or decrease a numeric value by a fixed `Increment`. The value is constrained between `Minimum` and `Maximum`.
