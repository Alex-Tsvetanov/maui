# NavigationPage (Controls).GetHasNavigationBar

> [!abstract] Method of [[NavigationPage (Controls)|NavigationPage (Controls)]]
> Namespace: `Microsoft.Maui.Controls`

Returns a value that indicates whether the `page` has a navigation bar.

## Signature

```csharp
bool static GetHasNavigationBar(Microsoft.Maui.Controls.BindableObject page)
```

## Parameters

| Parameter | Description |
|---|---|
| `page` | The `Page` being queried. |

## Returns

`true` if `page` would display a navigation bar were it the `CurrentPage`.
